# 第八十一階段：手冊保留原題與執行期倍率切換契約

狀態：進行中

## 目標

記錄使用者確認的手冊版面與倍率方向，將手冊覆繪固定為「保留上方原版題目、下方顯示
繁中段落」，並為遊戲執行中可在 2×／3× 切換建立不污染原版輸入的操作契約與實作邊界。

## 已確認決策

- 採用 Phase 62 方案 A：保留 `[7,312)×[7,72)` 原版題目，只覆繪下方
  `[7,312)×[72,184)`。
- 正文固定 36×14、容量 504 字；現有 22 筆正式譯文均能單頁顯示。
- 排除整框替換與另造中文題目提示；不改原版驗證、答案或輸入語意。
- 不設定唯一固定倍率；玩家可在遊戲執行中切換 2×（640×400）與 3×（960×600）。
- 採用 dosgolem 外層設定面板；排除直接快捷鍵與單鍵循環。面板與其操作完全屬 host，
  不得進入 DOS BIOS／IRQ 鍵盤佇列。

## 本階段決策前沿

- 查證 dosgolem 目前的 host 控制、視窗／輸出配置與鍵盤分流能力。
- 設定面板的開啟鍵、關閉／套用鍵、焦點規則、啟動倍率及設定持久化方式仍待逐項確認。
- 定義切換時 framebuffer、palette、overlay stamps、focus 與視窗尺寸如何保持一致。

## 不在本階段

- 不新增原版遊戲內選單項目，不修改 EXE、VRAM、存檔或 DOS 輸入。
- 不自行選擇面板開啟鍵、關閉／套用鍵、啟動倍率或設定持久化方式。
- 不把 prototype 當成完整正常玩家路徑收據。

## 完成條件

1. 手冊 504 字 validator、矩形及 spec 002 依已確認方案更新，不再保留 612 字 production 契約。
2. 倍率切換入口的 host／guest 輸入邊界、畫面重建與失敗模式達 READY。
3. 2×→3×→2× 切換後原版 framebuffer、輸入、事件與 active overlay 語意不變。
4. 專案測試通過、`main` 推送並更新相關 GitHub Issues。

## 退出條件

- 若現有 runtime 沒有 host-only 控制面，先補通用 dosgolem 能力，不把切換鍵送進遊戲。
- 若切換需要重新啟動或會丟失 overlay 狀態，先以可丟棄 prototype 呈現影響，不默認接受。
