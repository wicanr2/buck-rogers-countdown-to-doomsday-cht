# 第八十三階段：手冊保留原題的 504 字容量契約

狀態：完成

## 目標

依使用者已確認的「保留上方原版題目、下方顯示中文段落」版面，將正式手冊正文容量由舊的
36×17＝612 字收斂為 36×14＝504 字，並使 catalog validator、文字安全矩形與 spec 002
一致且失敗即關閉。

## 已確認前提

- 正文覆繪矩形是 `[7,312)×[72,184)`，不覆蓋原版頁碼、標題或序數。
- 22 筆已校訂譯文最長 236 字，均可單頁容納。
- 2×／3× 都是正式輸出模式；host 面板切換操作仍由另一分支處理。

## 範圍

- 查找所有把 612／36×17 當 production 契約的程式、測試與規格。
- 以 504／505 邊界、已知最長正式譯文與矩形幾何建立 validator 收據。
- 只修改手冊 catalog／layout 資料與其驗證，不接 presenter、不改原版輸入或答案判定。

## 完成條件

1. 正式單頁 validator 接受 504、拒絕 505；既有 22 筆皆通過。
2. 矩形、欄列、容量與 spec 002 互相一致，舊 612 production claim 不殘留。
3. 專案回歸通過；`main` 推送並更新相關 GitHub Issues。

## 退出條件

- 若任何既有譯文超過 504，不自動截斷或另開分頁；退回共同決策與 DRAFT 規格。
- 若矩形、字型 footprint 或原版題目保留證據衝突，先回到 RE，不以 validator 掩蓋幾何問題。

## 完成收據

- 新增 `text/manual-overlay-layout.tsv`，固定唯一正式正文矩形、36×14 格線、504 字容量與
  `single-page-reject` 策略。
- `tools/manual_catalog.py` 與 `tools/manual_overlay_layout.py` 都接受 504、拒絕 505；後者另拒絕
  schema 與幾何漂移。正式 22 筆段落全部通過，最長 236 字。
- spec 002、文字目錄與目前交接已改用 504 字 production 契約；612 字只在舊 prototype／歷史
  收據保留，不再作為可實作上限。
