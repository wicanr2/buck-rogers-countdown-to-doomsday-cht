# 第 18 階段：手冊題目世代與舊覆蓋失效

## 狀態

完成

## 本輪目標

以 dosgolem 的可重播狀態與追蹤能力，釐清手冊驗證答錯後從舊題目切換至新題目的玩家可見事件順序，並建立繁體中文覆蓋層不得沿用舊題翻譯的失效契約。

## 範圍

- 從既有手冊驗證狀態重播答錯路徑。
- 記錄舊題消失、畫面清除、新題字串輸出及新題畫面成立的先後關係。
- 以 dosgolem 執行位址空間、畫面雜湊或可重播收據，評估可供題目世代失效使用的最小證據。
- 將已證實、強推論、假說與未知分開記錄。
- 更新手冊覆蓋規格，但在規格仍為 DRAFT 時不接入正式執行路徑。

## 不在本輪範圍

- 不替使用者決定 2× 或 3× 字級方案。
- 不實作正式繁體中文覆蓋層。
- 不改變原版手冊問答、輸入或通過條件。
- 不以 DOSBox 收據取代 dosgolem 正式收據。
- 不深挖與玩家可見題目切換無關的程式流程。

## 證據與驗收條件

- 可由既有狀態以固定輸入重播至少一次答錯後換題。
- 收據能區分舊題世代與新題世代，並保存輸入、指令序號、執行位址空間及玩家可見結果。
- 明文寫出覆蓋層何時必須清除舊翻譯，以及目前證據能否作為可靠觸發。
- 所有新增研究結論均附推論等級與來源。
- 專案測試通過；本輪容器、擁有權與 Git 狀態完成檢查。
- 完成後推送 `main`，並更新 GitHub Issues #6 與 #8。
