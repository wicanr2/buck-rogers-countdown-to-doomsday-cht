# 第四十六階段：職業技能動作選單與確認離開證據

## 範圍與輸入

本階段沿用固定 state 與正常角色建立 BIOS 路徑，到達職業技能配置畫面後只操作原版輸入。
原版資料唯讀掛載；未使用 direct-entry、記憶體注入或自動分配。

## 已證實行為

- 預設動作下 Enter 對第一項技能加一點；Right 沒有 dispatcher 完成事件，但後續 Enter 以
  五筆事件把技能點、total 與剩餘點數還原。終點 framebuffer 與既有零點／Right 選取畫面
  逐 byte 相同，因此這是可執行的減點位置。
- 預設位置按 Left 會環回離開位置；加點後 Enter 顯示未用點數確認提示。此探針只定位動作
  次序，沒有把不可見反白文字登錄為譯文。
- 尚有 6 點未用時 Escape 先顯示確認提示；輸入 `Y` 後轉入技術技能配置畫面。新畫面共有
  62 筆完成事件，包含標頭、剩餘點數、欄名、十三列技能與第一列選取重畫。

## 正式收據

- 可逆減點：236 events；JSON `b513aae8…3cd3`，畫面 `5dc661e4…195`。
- 確認離開：289 events；JSON `68c586e4…f5b1`，畫面 `6bf7f9bb…432a`。
- 兩條分支各獨立重播兩次且逐 byte 相同。正式清冊只保存 identity、位置、色彩、step 與
  證據等級，不保存原版英文全文或動態數值。

## 證據限制

本階段沒有配置技術技能、沒有證實其動作選單與離開規則，也沒有證實角色建立流程的最終
完成畫面。職業技能的上限、bonus、total 公式與跨技能分配規則仍未推導。
