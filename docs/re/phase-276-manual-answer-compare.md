# 第二百七十六階段：手冊查詢題的答案比較語意

日期：2026-09-27
用途：規格 034（英文關鍵字列）的比較規則依據。本文件不含任何題目答案。

## 輸入

- 執行期 `2A33:0000` 8 KiB overlay 傾印（phase-12 同一份），SHA-256
  `7a2d9a3806d6ae49e5f8aa47a36767a38a0c1d1cbe744400e0525a98c4c2682c`，檔案只在 ignored `workplace/probe/`。
- 反組譯：Docker `python:3.13-bookworm` 內 `objdump -D -b binary -mi8086`，範圍 0x2F0–0x3D0。

## 流程（位址為 `2A33:` 執行期位移）

| 位址 | 原始指令（摘要） | 語意 | 等級 |
|---|---|---|---|
| `030E`–`031D` | `lea di,[bp-309h]` … `call 0000` | 以題目紀錄解碼答案到 `[bp-309h]`（`sub_0` 即 phase-12 的解碼分支） | 強推論 |
| `0320`–`032A` | `lcall 0CF4:0644`，目的 `[bp-105h]`，上限 0FFh | Pascal 字串指定：答案複製到 `[bp-105h]` | 強推論 |
| `032F`–`0340` | `lcall 0CF4:062A`，來源 `CS:0180`（長度 0） | 以空字串初始化暫存 | 強推論 |
| `0345`–`035D` | `lcall 0763:07E5`（參數 0Eh、0、14h）後指定到 `[bp-205h]` | 讀玩家輸入字串（上限推測 20） | 強推論 |
| `0362`–`039F` | 迴圈 i = 1..len，`lcall 0CF4:1CAD` 回寫 `[bp-105h+i]` | 答案逐字元轉大寫（Turbo Pascal `UpCase`） | 強推論 |
| `03A1`–`03A5` | `cmp byte [bp-4],3` / `je 03BD` | 某條件成立時直接視為通過（用途未知） | 未知 |
| `03A7`–`03B8` | `lcall 0CF4:072F`（輸入, 答案）/ `je 03BD` / `jmp 01A5` | 字串比較：相等 → 通過；否則回 `01A5`（重新出題） | 強推論 |

## 結論

- 比較是「玩家輸入」對「答案轉大寫」的**整串逐字元相等**，不去標點、不裁空白。
- 輸入端 `0763:07E5`（主程式段，反組譯）：以 `lcall 0C10:030C` 讀鍵，數字鍵盤掃描碼 47h–52h 換成數字
  字元，其餘 0x21–0x7A 的字元附加到輸入字串。
- 大小寫（已證實，執行期）：同一題以大寫與小寫各作答一次（`gba4` 起，按鍵時點同 phase-270 `gq2`），
  兩者都被接受並回到站內；phase-270 的 `gq2` 本身就是小寫作答。大小寫的轉換發生在讀鍵或比較程序內，
  位置未追。
- 答案欄容量 8 bytes（phase-12），所以答案最長 8 字元。
- `[bp-4] = 3` 的直通分支用途未知，規格 034 不依賴、不觸發。
