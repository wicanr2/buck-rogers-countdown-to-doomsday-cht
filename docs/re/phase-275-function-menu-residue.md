# 第二百七十五階段：角色建立功能選單的英文殘留

日期：2026-09-27

## 1. 前端發現（buckrogers-play 自動模式，Issue #27）

冷開機 → 種族選擇按 Esc → 功能選單 → 載入已存遊戲 → B 槽 → 開始冒險。
- 功能選單第 24 列 `SELECT` 為英文。
- 選「載入已存遊戲」按 Enter 後，該列顯示 `LOAD SAVED GAME`；讀檔後的選擇角色模式第三列
  `MODIFY CHARACTER` 為英文。

## 2. 追蹤（已證實，`bsave` 接 `Y`，帶暫存層）

| 呼叫端（執行期） | 內容 | 說明 |
|---|---|---|
| `37F1:15BD` | 五個功能項目，第 12–16 列第 9 欄 | 首次繪製（共用呼叫端，已覆繪） |
| `37F1:175D` | 選取項，前景 0 背景 15 | 反白繪製（共用呼叫端） |
| `37F1:1856` | 前一個選取項，前景 10 | 移動或按 Enter 時把舊選取項重畫成一般色；**不在 dispatcher 清單** |
| `37F1:101E` | `Choose a FUNCTION ` | 第 24 列提示（共用呼叫端） |
| `37F1:0243` | 單一項目 `Select `，第 24 列第 18 欄 | 水平選單；catalog 有 `Select`，查表命中 |

- `SELECT`：水平選單命中，但合成時規格 028 §3.4 以整列判讀讓位；舊選單家族在同列第 1 欄起
  畫了「選擇功能」，於是整頁不畫。
- 選定列：`1856` 的重畫不經任何家族，英文留在畫面上。`37F1` 當時是 unit `2BA60`。
