# 第三百一十五階段：第九頁的自然離頁（Issue #20）

日期：2026-10-01
狀態：第九頁的自然離頁已量到：Enter（與 Esc）進入下一幕。規格 022 維持原狀（固定入頁單行限縮 CONFORMED），本階段補的是離頁證據。
推論等級：**已證實**＝實跑並比對收據、看過畫面；**未知**＝未量。
原版與原文只在 ignored 的 `workplace/`；本文不引原文，只記步數、收據欄位與判定。

## 1. 起因

phase-219 只量到第九頁的 Ctrl+C（退出 DOS）與數字鍵盤 8、4、6、2（單鍵、限定時窗：故事矩形沒有相交寫入）。「遊戲內自然離頁」一直是未知。
第九頁是第八頁之後的最後一個固定單行（規格 022），不是終點：它只是開場敘事的最後一句，之後原版進入下一個事件。

## 2. 量測（已證實）

起點與工具：`workplace/page8-next-trace/page8-a.state`（合法第八頁）、runner（`cmd/buckrogers-text-receipt`，dosgolem `eee5b77`）、
原版 `workplace/original/BRcdoom`，依 phase-219 的步數：第 351,000,000 步送 Enter（進第九頁），再於第 361,000,000 步送一個鍵。

| 第九頁上送的鍵（第 361,000,000 步） | 結果 |
|---|---|
| Enter | 進入下一幕（全幅插圖與一個 ECL 敘事窗；runner 的 ECL 命中由 0 變 1） |
| Esc | 同 Enter |
| Space | 畫面不變，沒有新的文字呼叫 |
| ↑ | 沒有新的文字呼叫（與 Space 同樣的步數特徵；未另看畫面） |
| Tab、Y、不送鍵 | 沒有新的文字呼叫 |

（前三列的畫面都看過；第九頁以另一條路徑——從第九頁 state 直接送鍵——重做時結果相同。）

## 3. 各語言與倍率的收據（已證實）

同一起點、同一鍵序（兩個 Enter），zh-TW、zh-CN、ja、ko 與 `-lang en` 各跑一次（2×，停在第 358,000,000 步與第 380,000,000 步各一張），
另外 zh-TW 與 en 再以 3× 各跑一次：

- 收據的 `events`、`requests`、`catalog_misses`、`bios_keys`、`overlay_scale`、`overlay_actions`、`overlay_drew`、`memory_sha256`、`cpu_sha256`
  在英文與四個語言之間逐項相同（2×）；3× 的 zh-TW 對 en 同樣只有 `live_language`、`live_load_ms` 不同。語言不影響遊戲狀態。
- 第九頁（第 358,000,000 步）：四個語言都畫出該語言的單行（繁、簡、日、韓）。
- 離頁後（第 380,000,000 步）：各語言畫出下一幕的敘事，第九頁的單行已不在畫面上，沒有殘字（2×、3× 目視）。

## 4. 未做

- 離頁時刻的 RGBA 逐像素 A/B（control／2×／3× 的「差異限於核准矩形」）沒有做；本階段只有收據欄位相同與畫面目視。
- 存讀檔經過第九頁的情境未量。
- Ctrl+C 之外的其他出口（如 F 鍵、滑鼠）未量；已量的自然離頁是 Enter 與 Esc。
