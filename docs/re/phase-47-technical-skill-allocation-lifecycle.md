# 第四十七階段：技術技能配置生命週期證據

## 範圍與輸入

本階段從固定 state 經完整正常角色建立 BIOS 路徑，於職業技能頁 Escape→`Y` 後到達技術
技能配置畫面。原版資料唯讀掛載；沒有 direct-entry、記憶體注入或自動配置。

## 已證實行為

- Down 以八筆事件把第一列取消選取、第二列設為選取。
- 預設動作 Enter 合法增加第一項技術技能一點；Right→Enter 再以五筆重畫還原。加後減終點
  逐 byte 等於零點／Right-only 技術技能畫面。
- Escape 顯示長度 34 的未用點數確認 identity；`N` 後逐 byte 回到技術技能基線。
- Escape→`Y` 進入角色身體圖示選擇畫面；新終點可見新舊兩組圖示及完成動作，正式收據固定
  六筆新畫面文字事件，不保存原版英文全文。

## 正式收據

選取、可逆減點、拒絕離開與確認離開分別為 297／299／290／296 events。四條分支各獨立
重播兩次，JSON 與 64,000-byte framebuffer 均逐 byte 相同；清冊保存 identity、step、位置、
色彩與證據等級，動態點數不列為譯文。

## 證據限制

本階段沒有操作身體圖示選擇、沒有確認角色建立完成後的下一畫面，也沒有推導技術技能上限、
bonus、total 或職業限制。
