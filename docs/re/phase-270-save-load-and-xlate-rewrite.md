# 第二百七十階段：存讀檔路徑與疊字層改寫偵測

日期：2026-09-27
相關：Issue #25；dosgolem 規格 204、239（`bad09fc`）。

## 1. 存檔對話框「卡住」的原因（已證實）

- 選槽後，原版反覆呼叫 INT 21h：`AH=4Eh`（CX=0x10）找 `C:\BUCK\SAVE`，找不到就 `AH=39h`
  建目錄再找（`buckrogers-glyph-text -int-log` 記到 5 萬次以上）。
- dosgolem 規格 204：沒有暫存層時建目錄只記帳，搜尋永遠找不到。追蹤工具原本沒有暫存層選項；
  補上 `-scratch` 後，存到 B 槽寫出 `savgamB.dat`、`CHRDATB1–6.sav/.stf`（只在 ignored 工作區）。
- 讀檔：角色建立流程的功能選單（`bsave` 接續按 `y`）→ Load Saved Game → B，隊伍載回。

## 2. 讀檔後的殘留（已證實）與修正

- 讀檔後隊伍選單第 24 列顯示成 `PICK CH RACTER`：舊選單家族先把 `Choose a FUNCTION ` 覆繪成中文，
  原版改印 `Pick Character ` 時兩串第 8 格都是 `A`，xlate 的逐格指紋不變，舊遮罩留下那一格。
  以停用通用家族的對照實驗、與舊選單家族單獨輸出確認來源。與讀檔無關，一般操作也會發生。
- dosgolem 規格 239（xlate 改寫偵測）修正後：舊選單家族輸出第 24 列與原畫面相同；原本因那一格
  而讓位的通用家族也畫出「選擇角色　選擇(S)　離開(E)」。
