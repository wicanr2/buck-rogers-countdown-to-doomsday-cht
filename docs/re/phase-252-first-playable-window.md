# 第二百五十二階段：第一個可玩的 Linux 視窗

日期：2026-09-26  
狀態：**已證實（Xvfb 自動模式）；實體桌面互動未驗。**

## 內容

dosgolem fork `64634c3` 的 `cmd/buckrogers-play`：

- `bootroot.Prepare` 複製原版樹為存檔樹，sealed Owner 冷開機；存檔根同時是
  Scratch，遊戲存檔落地（規格 235 補充）。
- 每個 host 畫格（60 Hz）推進 192,500 步，對應原版 70 Hz 回掃每 165,000 步。
- 掛上即時覆繪觀測器（目前只有選單家族），2×／3× 合成顯示，F2 切換倍率，
  F2 不送進遊戲。
- 輸入：可列印字元經 `AppendInputChars` 轉 BIOS 鍵；Enter、Esc、Backspace、Tab、
  方向鍵、Home／End／PgUp／PgDn、Insert／Delete 走具名鍵。尚無設定面板與滑鼠。

## 驗證

- Xvfb 自動模式：第 623、779 格送空白鍵，跑 1,300 格截圖。2× 與 3× 截圖分別與
  第二百五十一階段無頭輸出逐位元相同（種族選擇屏繁中）。
- 速度：觀測路徑原本每步裝箱 `StepView` 並逐步 `defer recover`，250M 步掛觀測器
  79 秒；改用 `StepCursor` 並把 recover 移到迴圈外層後，與無觀測器相當（約 21–28 秒）。
  Xvfb 下 2× 約 1,300 格／22–30 秒，接近 60 fps；3× 約 22 fps，瓶頸是 Xvfb 軟體繪圖。
  曾嘗試以像素比對快取合成結果，但覆繪層在畫面不變時也會隨回掃改變狀態
  （Pending 轉 Shown、錨定失效累計），快取會顯示舊畫面，已撤回。

## 限制

- 即時覆繪只含選單家族（選單、性別、職業、名冊、角色頁、命名、職業／技術技能）。
  劇情頁、操作列、離開問句、身體圖示、手冊等尚未搬入，這些畫面會顯示英文。
- 實體桌面的鍵盤互動、長時間遊玩與存讀檔未驗。
