# 第二百六十階段：物品名單字表

日期：2026-09-26  
狀態：**已證實（執行期記憶體）；物品記錄如何引用單字索引未量。**

## 位置與格式

`workplace/phase257-text-window-trace/cp/x1.state`（841.5M，戰鬥中）的 1MB 記憶體傾印
（ignored `mem.bin`）：DS = `0EC0`，單字表從線性 `0x108E2`（`DS:1CE2`）起，
每筆 21 位元組 = Pascal string[20]（長度位元組＋20 字元，未用部分補 0），連續 54 筆。
內容是武器、護甲、手榴彈、裝備的組成單字，含少數兩字詞組與縮寫（如發射器縮寫、
附力場）。前後的記錄格式不同，視為表的邊界。

`START.EXE` 檔案內同一批字串之間夾有 `nn 00 b2 00 nn 00 b0` 樣式，與記憶體版不同，
推測執行檔經過壓縮；檔案位移不能當執行期位址。

## 與戰鬥畫面的關係

戰鬥右欄武器行（`1FEB:05E7` → `0763:056C`）的內容是兩個單字以空白相接、再接括號數字，
兩個單字都在此表內。這支持「物品名 = 單字表單字串接」，但物品記錄的索引欄位未反組譯。

## 推論等級

- 表的位置、筆寬、筆數：已證實（單一存檔）。
- 物品名由此表單字串接：強推論。
