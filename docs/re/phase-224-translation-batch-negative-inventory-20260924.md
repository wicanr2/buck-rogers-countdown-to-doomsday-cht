# 第二百二十四階段：未譯安全區候選負面盤點

日期：2026-09-24
狀態：負面盤點完成；本批次沒有符合條件的新增譯文。

## 範圍與判準

只尋找同時具有已證實原文身分、玩家可見輸出路徑及文字安全矩形，且尚未連到繁中顯示 key 的短字串。原文只以既有 identity／callsite 證據回查，不在本文複製。

## 盤點結果

Docker 內讀取 24 份正式 `*.zh-TW.tsv`，共 196 筆。將帶有文字安全矩形的靜態輸出家族逐一連回事件表的 `text_key`（技能操作列依其事件 key 對照），再比對正式 catalog：

|---|---:|---:|---:|---:|
| 身體圖示 | 7 | 7 | 7 | 0 |
| 職業技能頁 | 14 | 14 | 12 | 0 |
| 角色資料頁 | 35 | 35 | 35 | 0 |

| 性別選擇頁 | 7 | 7 | 3 | 0 |

| 姓名提示 | 1 | 1 | 1 | 0 |

| 技能操作列 | 8 | 16（一般／焦點） | 5 | 0 |
| 技術技能頁 | 17 | 17 | 15 | 0 |

較少的 catalog 筆數是多個 event identity 共用同一顯示 key，不是漏譯。十個家族均無缺少的譯文 key，也沒有事件缺少安全矩形。

格式與字元基線由 Docker 內的 `tools/catalog_font.py chars` 重新檢查：24 份 catalog 各自通過 UTF-8／欄位／檔內 key 唯一性／來源值／控制字元／NFC 檢查。此命令刻意允許不同 catalog 共用同一顯示 key，**不**檢查跨檔 key 唯一性。產生的需求清單為 1,025 個不同字元，與版控內 `font/characters.txt` 逐位元相同，SHA-256 為 `eee90d5182a49f21260911b2a56913a809ec4ed2157767188135ac5a3e1fa23e`。因此本批次沒有新增字元，也沒有重建或修改字型。這項清單比對不等於重新檢查本機 GOLEMFNT 二進位字模。

## 不納入翻譯的候選

- row 15 命令／狀態輸出已有合法重播、原文 identity 與輸出 callsite 證據，但第一百三十六階段及本日追加比較只證明動態重畫；其中孤立字母不是可辨識固定詞。跨狀態固定語意及文字安全矩形仍未知，維持 DRAFT，不建立固定譯文。詳見[第二百二十一階段](phase-221-command-status-columns-draft.md)及其引用的第一百三十六階段。
- 所謂第十頁故事輸出只在合法 Enter 後重畫 row 15；收據沒有 story-region 寫入或 glyph-return edge，沒有新的固定故事字串。未建立第十頁事件表或 catalog。詳見[第一百三十六階段](phase-136-story-page10-enter-stop-line.md)。
- 其餘動態欄位、未觀測 identity 或僅有推測的功能選單文字，欠缺穩定固定字串或安全矩形證據，不符合本批判準。

## 結論與限制

本批次沒有新增正式譯文，`text/` 與字型產物均未修改。結論僅限目前已記錄且具有安全矩形的靜態輸出 identity；不表示未觀測畫面已盤完，也不構成正常玩家路徑或原版／繁中同狀態符合證明。
