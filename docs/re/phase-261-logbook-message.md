# 第二百六十一階段：手札訊息的組字程序

日期：2026-09-26  
狀態：**已證實（位元組）；執行期觸發未量。**

## 來源

`GAME.OVR` 檔案位移 11,669 起的常數與其後程式（`objdump -mi8086`，ignored
`workplace/logbook-l10n/ovr.bin`）。位址以檔案內相對位移表示；overlay 在 841.5M 的
記憶體傾印中未載入，執行期段位址未知。

## 結構

常數依序（Pascal 字串，程式以 `CS:2490`、`CS:24A1`、`CS:24B4` 引用）：

| 引用 | 長度 | 內容形狀 |
|---|---|---|
| `CS:2490` | 16 | 以空白開頭的「並記錄」前句 |
| `CS:24A1` | 18 | 「為手札第」句 |
| `CS:24B4` | 1 | 句點 |

程式（相對 `0xA8` 起）：

1. 以兩次 `lcall 00B8:002A`／`00B8:0025` 讀 ECL 指令的兩個運算元，第二個存 `[bp-103h]`。
2. 串接：`CS:2490` ＋ `DS:6EDC`（字串變數）＋ `CS:24A1` ＋ `0653:13AC`（整數轉字串，
   參數 `[bp-103h]`）＋ `CS:24B4`。
3. 以 `DS:5F40`–`5F43` 為視窗、顏色 10、清窗旗標 0，呼叫 `lcall 0653:056C`
   （執行期 `0763:056C`，規格 027 的敘事窗程序）。
4. 之後串接 `CS:24B6`（長度 0 的空字串，審查時讀出）並呼叫 `00B8:007F`（推測為等待按鍵）。

## 結論

- 手札訊息是接在前一段敘事之後的接續字串（旗標 0），結尾固定為「數字＋句點」。
- 手札編號來自 ECL 指令運算元，不在劇本字串裡。
- `DS:6EDC` 的內容未量（推測為物品或記錄對象的名稱）。

## 推論等級

- 串接順序、視窗、旗標：已證實（位元組）。
- `00B8:007F` 的作用、`DS:6EDC` 的內容：推測。

## 補充：觸發指令（2026-09-26）

- `GAME.OVR` overlay 以 `TPOV` 開頭。從執行期記憶體的 34 筆 control record（`CD 3F`，
  檔案位移串成鏈）查得手札組字函式在 control segment `0145`（檔案位移 2,308 起）
  的 code offset `24B7`，是該段第 54 個 entry。
- 同段 `2DCC` 起的 ECL 分派鏈以 `DS:6D13`（原始 opcode）逐一比較，`cmp al,3Fh` 後
  `call 24B7`：**手札是 ECL opcode `0x3F`**（已證實，位元組）。
- 運算元：第 1 個是 6-bit 字串（記錄的對象，如「它」「他的演說」），第 2 個是位元組
  立即值（手札編號）。字串運算元即組字時的 `DS:6EDC`（強推論）。
- 以此形狀掃 ECL1–6，得 30 個觸發點（ignored `workplace/logbook-l10n/triggers.txt`）；
  最早的是 `ECL1` 區塊 17 位移 181 的第 41 則，位於太空港任務後與指揮官會面的段落。
  其餘 41 則的編號不是立即值（或由其他指令產生），未量。
