# 第二百五十五階段：ECL 敘事窗印字程序 `0763:056C`

日期：2026-09-26  
狀態：**已證實（位元組＋單一路徑執行期）；翻頁與接續字串的執行期行為未量。**

## 工具與輸入

- dosgolem fork `cmd/buckrogers-glyph-text`：本機診斷工具，從 savestate 執行，記錄
  glyph primitive、dispatcher、`0763:056C` 進入、清除呼叫與敘事窗區 A000 寫入叢集。
  輸出含原版文字，只寫 ignored `workplace/phase257-text-window-trace/`。
- 起點 `workplace/phase104-manual-correct-return/control.state`，281M 起每 10M 送 Enter，
  跑到 400M／700M。
- 程式碼：同一 state 結束時傾印 `0763:0000`–`0C00`，`objdump -mi8086` 反組譯。
  位址是 dosgolem 實模式 `segment:offset`。

## 程序結構

| 位址 | 內容 |
|---|---|
| `0763:056C` | `push bp; mov bp,sp; sub sp,126h`，把 `[bp+6]` 遠指標的 Pascal 字串複製到區域 `[bp-100h]` |
| `0763:058C`–`05A4` | 依序要求 `[bp+16h]` 左欄 ≤ 27h、`[bp+14h]` 頂列 ≤ 18h、`[bp+12h]` 右欄 ≤ 27h、`[bp+10h]` 底列 ≤ 27h；任一不符直接返回 |
| `0763:05A7`–`05D0` | 游標 `DS:5F3E`（欄）、`DS:5F3F`（列）不在視窗內時設為左上角 |
| `0763:05D3`–`05F6` | `[bp+0Ah]` 非零時呼叫 `0763:110F` 清窗，游標設為左上角 |
| `0763:0628`–`06FE` | 以 `0CF4:0831`／`0CF4:08DF`（集合包含測試，集合在 `DS:0EA0`）找下一個斷字點 |
| `0763:0700`–`0724` | 目前欄加上單字長度超過右欄時換行 |
| `0763:0763`–`076F` | 換行：欄回左欄、列加一，`0763:0530` 略過行首空白 |
| `0763:0772`–`07AF` | 列超過底列且字串未完：游標回左上，`0763:1291`、`09BD:03E4` 後 `0763:110F` 清窗，再印 |
| `0763:04B3` | 巢狀程序：逐字呼叫 glyph primitive `0763:026B`（返回位址 `0763:04FF`），每字後 `0C10:029E` 延遲，欄加一 |
| `0763:07E0` | `RETF 12h`：參數 9 個 word |

`[bp+0Ch]`、`[bp+0Eh]` 是傳給 glyph primitive 的兩個色彩位元組（執行期 0、10）。
