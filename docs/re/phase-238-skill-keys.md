# 第二百三十八階段：技能屏按鍵語意（武裝需求）

狀態：**已證實／單次重播各一。**

## 觀測（皆由 `skill504.state` 展開，BDA 定時鍵）

- Escape（504.1M）：被取走（int16-AH00），僅一次內部
  "Character name: " 字串準備，VRAM 零差異至 510M。
  零配置時無離開問句（與問句本體「尚有點數未使用」一致）。
- Enter×2＋Escape（504／506／508M）：三鍵皆取走，畫面凍結
  （`c58d13c2…` 不變）。**Enter 單獨無效。**
- Down,Up,Enter（504／505／506M）：進 80 點配置表
  （`edfdc9b2…`，phase-237），`alloc508.state` 已入庫；
  重播同雜湊。

## 結論

進入配置表的 Enter 需要 Down／Up 先武裝（Down／Up 各觸發一次
內部單值重畫 "2"／"8"，疑似游標或計數器狀態遷移；確切語意未定，
不猜）。零配置的 Escape 是取走無動作。後續配點實驗
（加點鍵、Escape→Y 問句）由 `alloc508.state` 展開，另案。
