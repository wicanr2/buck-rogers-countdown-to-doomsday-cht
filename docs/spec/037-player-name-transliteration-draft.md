# 037 — 英文姓名自動音譯器

狀態：**READY**（2026-09-29，兩輪獨立審查後；第一輪後拆出玩家名判定與顯示接線，另立規格 038）
日期：2026-09-29
Issue：#33
前置：規格 024／031（字型）、036（譯名表）。使用端：規格 038（玩家名判定與各畫面顯示，待逆向證據）。

## 1. 為什麼要做

使用者決定（2026-09-29）：玩家輸入的英文角色名在遊戲內顯示為「中文(英文)」，中文部分自動音譯，採新華社
英語姓名譯名風格。本規格只定義音譯器：輸入名字與性別，輸出繁體中文或「無法音譯」。它是純函式庫，不依賴
原版證據，可獨立驗收。

## 2. 證據（本機調查，報告不入庫）

- 新華社《英語姓名譯名手冊》與 GB/T 17693.1 的表格受著作權保護，不照搬（已證實，出處見調查報告）。
- 中文維基「Wikipedia:外語譯音表/英語」人名表依《世界人名翻譯大辭典》整理，CC BY-SA 4.0；以國際音標音素為鍵
  （26 輔音欄 × 17 元音列＋單獨輔音列），附註規則部分要看拼寫；人名表繁體化後約 290 字（已證實，解析 wikitext）。
- CMU 發音詞典約 13.4 萬詞、ARPAbet 39 音素、元音帶重音標記，BSD 式授權，散布須保留聲明（已證實）。
- 原版角色名可含數字、空白、`.`、`?`，也可只有一個字元（已證實，phase-244）。

## 3. 契約

### 3.1 介面（通用層 `xlate/translit`，Go）

- `Transliterate(name string, gender Gender) (zh string, tier Tier, ok bool)`；`Gender` 為 Unknown／Male／Female。
- 名字先轉大寫、以空白切成字；**任一字含 A–Z、`'`、`-` 以外的字元時整名 `ok=false`**（呼叫端顯示英文）。
- 只有一個字母的字（例 `Z`）視為無法音譯，整名 `ok=false`：單一字母的讀音是字母名稱，不是人名發音。
- `'`、`-` 不發音：查詞典與 CMUdict 時保留原拼寫；拼寫後備時先去掉再切音節。
- 逐字音譯後以 `•`（U+2022）連接。`tier` 取各字中最低的來源等級：`dict` ＞ `cmudict` ＞ `spelling`。
- 決定性：同一組 (name, gender) 永遠同一輸出；不寫檔、不進存檔。
- 輸出每個字都必須在「允許字集」內（§3.4）；否則 `ok=false`。

### 3.2 查找順序（每個字）

1. 專案詞典 `text/translit-names.tsv`：`english`、`gender`（M／F／空＝不分）、`chinese`、`basis`（`reviewed`、
   `wikidata-cc0` 等）。性別相符者優先，其次不分性別者。人工審定，可放台灣慣用譯名（例 NICOLE→妮可）。
2. CMU 發音詞典（`text/cmudict/`，全文與授權隨發行包）取第一個讀音，依 §3.3 轉成漢字。
3. 拼寫後備：字母組合 → 近似音素 → §3.3。品質最差，但執行期必須給出結果；以 `tier=spelling` 標示，
   供呼叫端與診斷區分。（調查報告建議拼寫結果不上畫面；本專案的名字是玩家在遊戲中當場輸入，
   無法先人工審，所以採「照常顯示、標等級」，並以專案詞典逐步覆蓋常見名。）

### 3.3 音素到漢字

- 譯音表 `text/translit-table.tsv`：由上述維基頁面的人名表轉錄並轉繁體，記錄頁面 revision id；授權與出處、
  修改說明寫在 `text/LICENSE-translit-table.md`（CC BY-SA 4.0，與程式授權分開）。
- ARPAbet 到表的音素欄／元音列對照：`text/translit-arpabet.tsv`（專案自製）。
- 音節切分：以元音為核，前方輔音歸該音節（最多取一個，其餘作單獨輔音）；詞尾輔音用「單獨輔音」列。
- 採用的附註規則（每條配單元測試）：
  1. 詞首 a 讀 [ə] 時按 [ɑː] 列；
  2. 詞尾 ia 的 a 譯「亞」；
  3. 詞首 ai／ay 按「艾」列；
  4. 詞尾 r／re 讀 [ə] 時譯「爾」；
  5. tr／dr 按表中合讀列；
  6. m 在 b／p 前按表中規則；
  7. 詞首 [f] 用「弗」；
  8. th 在輔音前或詞尾譯「思」；
  9. 非重音節的元音按拼寫譯（依 CMUdict 重音標記判斷）；
  10. 女性名（`gender=Female`）改用表中女名用字（婭、瑪、琳、娜、麗、莉、莎、黛、絲、妮等），「西」音作「茜」。
- 排除的規則：地名表專用規則（詞首東、南、西改用棟、楠、錫；詞尾海改用亥），人名不套用。
- 規則精確條文在實作時照頁面轉錄；與上列有出入時以頁面為準並回寫本節。

### 3.4 允許字集與字型

- 允許字集 = 譯音表全部用字 ∪ 專案詞典全部用字（繁體）。工具 `tools/translit.py chars` 產生
  `text/translit-chars.zh-TW.tsv`（一列一字，進正式 catalog），字型子集因此固定包含這些字。
- 專案詞典 lint：每個 `chinese` 的字都要在允許字集內，新增字要同步重建字型。

## 4. 不做什麼

- 判斷字串是不是玩家名、各畫面怎麼顯示（規格 038）。
- 以中文輸入名字、音譯結果寫入存檔。
- 非英語名字的專門規則（照英語處理）。

## 5. 驗收

1. 單元測試：§3.3 每條附註規則；三層查找各有命中樣本；性別切換改變用字；多字名以 `•` 連接；含數字或標點的名字
   （`A 1.?`、`R2D2`）與單一字母名（`Z`）回 `ok=false`；含撇號或連字號的名字（`O'BRIEN`、`MARY-JANE`）正常音譯；允許字集外的字回 `ok=false`；決定性。
2. 固定測試名單與期望輸出（人工審定後入庫）：ROARKE、CELESTE、FLAVIUS、JANELLE、PIERRE、NICOLE STEELE，
   以及 BUCK、WILMA、PORT、EXIT 等與 NPC 或 ECL 短詞同形的名字（只驗音譯本身）。
3. 譯音表轉錄：每格與記錄的 revision 一致（工具重抓比對）；授權檔齊全；CMUdict 授權全文隨發行包。
4. 字型重建零缺字。
