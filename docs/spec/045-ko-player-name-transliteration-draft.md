## 1. 為什麼要做

同規格 044 §1：韓文模式的玩家名以諺文音譯，格式「譯名(英文)」，窄欄只顯示譯名。規格 043 §3.8 讓 ko 的 `PlayerNames` 停用（名字維持英文），本規格補上韓文音譯器。

## 2. 證據（已證實，除非標明）

- 接線點、CMUdict 覆蓋、原版名字限制、共同前端問題統計：見規格 044 §2。
- 韓文字型字集（`font/charset.ko.txt`，11,273 字）含全部 11,172 個諺文音節；現行字型子集（`font/characters.ko.txt`）含其中 1,057 個，其中 764 個在本規格的允許字集內；音譯輸出要保證渲染，字型子集必須先含全部可能輸出的音節。
- 規格 043 §3.2：ko 禁用 `·`（U+00B7）與全形英數；名字表（`text/name-glossary.ko.tsv`）寫多字名用單一空白，例 `알렉산더 윌리엄스`。規格 043 §3.8 的「單一內部空白」限制只在名字表載入端（`allowSpace` 拒絕首尾與連續空白）。
  ECL 排版端（`eclWordTokens`）把整個名字單元（含其內任意個空白）當一個 token，單元加黏著字寬於視窗時才在單元內每個空白前切開，兩者沒有關聯；音譯器輸出的多字名以單一空白分隔、字數不限，排版端不需要另外支援。
- 韓國《外來語標記法》的英語標記規則（國立國語院公告）是公開的標準；本規格的規則依其音韻對應整理，細節由專案詞典與固定名單校準，**母語者未校對**（§6）。慣用並存的點（`Bob` 보브與밥、`Thomas` 토머스與토마스）無法由單一規則涵蓋，進專案詞典。

## 3. 契約

### 3.1 介面、查找、前端

同規格 044 §3.1 至 §3.3：套件 `xlate/translitjk`，`Load(textDir, "ko")`，專案詞典 `text/translit-ko-names.tsv`，CMUdict，拼寫後備（`translit.SpellingPhones`），共用前端 F1 至 F8（元音字母對齊、單一聲母音節化、輔音＋`Y`＋元音、元音後的 `R`、詞尾 `TS`/`DZ`、無元音的字 `ok=false`）。允許字集檢查豁免 U+0020 與 `-`（規格 044 §3.1），ko 的輸出以它們連接多字與連字號段。

### 3.2 韓文：音節到諺文

規則編號 `K1` 至 `K10`；每條至少一個固定測試名（規格 044 §5 第 1 點的規則追蹤）。括號內的例子是意圖，全部抽成 `docs/re/phase-NNN-spec-examples.ko.tsv`，以規則模式逐列比對（規格 044 §5 第 1 點）；慣用寫法與交詞典的例子標 `kind=idiom`。
音節為（頭子音、中聲、尾聲）三元組，以 Unicode 算式合成（`0xAC00 + (頭×21 + 中)×28 + 尾`）。尾只用 `ㄱ ㄴ ㄹ ㅁ ㅂ ㅅ ㅇ`；沒有促音、沒有長音符號。

**K1 頭子音（接元音時）。** `P`→ㅍ，`B`→ㅂ，`T`→ㅌ，`D`→ㄷ，`K`→ㅋ，`G`→ㄱ，`F`→ㅍ，`V`→ㅂ，`TH`→ㅅ，`DH`→ㄷ，`S`→ㅅ，`Z`→ㅈ，`CH`→ㅊ，`JH`、`ZH`→ㅈ，`M`→ㅁ，`N`→ㄴ，`L`、`R`→ㄹ，`HH`→ㅎ；`NG` 不當頭。
`SH` 在元音前為ㅅ加舌面中聲：`샤`（`AA`）、`섀`（`AE`）、`셔`（`AH`、`ER`）、`셰`（`EH`）、`쇼`（`AO`、`OW`）、`슈`（`UW`、`UH`）、`시`（`IH`、`IY`）；無重音 `AH` 拼作 a 時取 `샤`（`Patricia` 퍼트리샤）；雙元音取其第一元音套用此列。

**K2 中聲。**

| 音素 | 中聲 | 備註 |
|---|---|---|
| `IY`、`IH` | ㅣ | |
| `EY` | ㅔ＋`이` | 拆成兩個音節：`Kate` 케이트 |
| `EH` | ㅔ | |
| `AE` | ㅐ | |
| `AA` | ㅏ；字母組以 o 起首時為ㅗ | `Scott` 스콧 |
| `AH` | 有重音：ㅓ；無重音：字母為 i 時ㅣ（`Jennifer` 제니퍼、`Justin` 저스틴）；`S` 之後拼作 o 且其後為 `N`（-son）時ㅡ（`Jackson` 잭슨、`Hudson` 허드슨）；字母為 a 時詞尾ㅏ（`Sarah`、`Linda`）、詞中ㅓ（`Adam` 애덤、`William` 윌리엄）；其餘ㅓ。**例外（2026-10-01 審查修訂）**：F1 把 `ER0` 改成 `AH0`、且其後的元音有重音、字母為 a 時取ㅏ（`Marie` 마리、`Maria` 마리아；原規則得 머리、머리아，`Marie` 會被讀成 `Murray` 的慣用譯名 머리）。後接無重音元音時不適用（`Barbara` 바버라、`Margaret` 마거릿）；全字典 481 詞受影響 | |
| `AO`、`OW` | ㅗ | |
| `UW`、`UH` | ㅜ | |
| `AW`、`AY`、`OY` | ㅏ＋`우`、ㅏ＋`이`、ㅗ＋`이` | 同 `EY`，拆兩個音節 |
| `ER` | ㅓ（r 不另譯） | `Peter` 피터 |

半元音：`Y`＋元音得 `야`（`AA`、`AE`）、`여`（`AH`、`ER`）、`예`（`EH`）、`유`（`UW`、`UH`）、`요`（`AO`、`OW`）、`이`（`IY`、`IH`）；`Y`＋雙元音取第一元音。`Y` 在詞尾（不接元音）補 `이`。
`W`＋元音得 `와`（`AA`）、`왜`（`AE`）、`워`（`AH`、`AO`、`ER`）、`웨`（`EH`）、`위`（`IH`、`IY`）、`우`（`UW`、`UH`、`OW`）；`W`＋`EY` 為 `웨`＋`이`，`W`＋`AY` 為 `와`＋`이`，`W`＋`AW` 為 `와`＋`우`，`W`＋`OY` 為 `워`＋`이`。`W` 在詞尾（不接元音）補 `우`。`Y`、`W` 在輔音前同詞尾，補 `이`、`우`；獨立的 `R`（不在元音後、也不接元音）補 `르`。字母組以 `w` 結尾時，K2 的「字母」取其前一個字母。無重音 `AH` 的字母判讀取字母組的末位字母（規格 044 F2）。

**K3 輔音＋`Y`＋元音（`Pal`）。** 輔音加 `ㅠ` 後接 `UW`、`UH`，以及字母為 u 的無重音 `AH`（`큐`、`휴`、`뮤`、`뷰`、`퓨`、`규`、`뉴`、`류`、`듀`、`튜`；`Hugh` 휴、`Cuba` 큐바、`Regular` 레귤러、`Accumulate` 어큐뮬레이트）；輔音＋`Y`＋無重音 `AH` 時輔音加 `ㅣ`，再接獨立音節，母音依 K2 的 `AH` 字母表取音（`Julia` 줄리아、`William` 윌리엄、`Daniel` 대니얼）；其餘元音取 K2 半元音列。`Pal` 的輔音不得補 `으` 當獨立音節。`SH`、`CH`、`JH`、`ZH`、`DH` 在 `Pal` 時與 K1 相同取頭子音（`샤 슈` 等為 K1 的 `SH` 列；`ㅈ`、`ㅊ` 與 `ㅑ ㅕ ㅛ ㅠ` 的結合是否採用由母語者決定，見 §6）。

**K4 元音後的 r（`R=true`）。** `EH R`、`IH R`、`IY R`、`UH R`、`UW R` 在詞尾或輔音前時，元音後補獨立音節 `어`（`Clare` 클레어、`Pierce` 피어스、`Moore` 무어）；`AA R`、`AO R`、`ER` 等其餘情形 r 不譯（`Park` 파크、`Port` 포트）。
有 `R=true` 的元音在 K6 不算「短元音」（`Park` 的 `K` 補 `으` 得 `크`，不得 `팍`）。

**K5 `L` 疊寫。** `L` 在元音前（含 `L`＋`Y`＋元音的 `L`），且不在詞首、前一個音素不是 `M`、`N`、`NG` 時，前一音節（或前一個補出的 `으` 音節）加尾 `ㄹ`，`L` 本身仍作頭 `ㄹ`（`Sally` 샐리、`Kelly` 켈리、`Clark` 클라크、`Blake` 블레이크、`Allen` 앨런、`William` 윌리엄）。前一音節已有尾時不疊（`Candlelight` 캔덜라이트）。詞首的 `L`、`M`／`N` 之後的 `L` 不疊（`Lee` 리、`Stanley` 스탠리、`Hamlin` 햄린）。

**K6 無聲塞音 `P`、`T`、`K`（不接元音時）。** 緊接在**短元音**（`IH EH AE AH AA UH`，且 `R=false`）之後，且在詞尾，或後面接 `L R M N` 以外的輔音時，為尾 `ㅂ`、`ㅅ`、`ㄱ`（`Jack` 잭、`Scott` 스콧、`Jackson` 잭슨、`Garrett` 개릿）；其餘情形補 `으`（`프`、`트`、`크`）。有重音與否都適用。

**K7 其他輔音（不接元音時）。** `B D G F V TH DH S CH JH ZH` 補 `으`：`브 드 그 프 브 스 드 스 치 지 지`；`SH` 在詞尾為 `시`、在輔音前為 `슈`；`HH` 補 `흐`；詞尾 `TS`、`DZ` 為 `츠`、`즈`（`Roberts` 로버츠、`Edwards` 에드워즈）。
詞尾 `Z`：拼寫以 s 結尾且前一個音素不是 `D` 時取 `스`（`Jones` 존스、`Williams` 윌리엄스、`Rogers` 로저스），其餘取 `즈`（`Rose` 로즈、`Woods` 우즈）；`Z` 在輔音前取 `즈`。

**K8 鼻音與 `L`（不接元音時）。** `M`、`N`、`NG` 為前一音節的尾 `ㅁ`、`ㄴ`、`ㅇ`，`L` 為尾 `ㄹ`（`Bill` 빌、`Walt` 월트）。前一音節已有尾、或詞首沒有前一音節時，`M`、`N`、`L` 以 K1 的頭子音補 `으` 成獨立音節（`므`、`느`、`르`；`Mbeki` 므베키）；`NG` 前面一定是元音，沒有此情形。補音的字形（`므` 與 `름` 等慣用）由母語者確認，見 §6。

**K9 不得出現的形式。** 輸出每個字元都是允許字集的音節、空白或 `-`；沒有單獨的子音字母（Jamo）、沒有 `·`。

**K10 組成。** 多字名以單一空白（U+0020）連接；連字號的各段以 `-`（U+002D）連接。`tier` 取各字最低。

### 3.3 允許字集、檔案與工具

- 專案詞典 `text/translit-ko-names.tsv`；允許字集檔 `text/translit-chars.ko.tsv`（格式與工具同規格 044 §3.5）。允許字集 = 頭子音 14 個（`ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ`）× 中聲 19 個（`ㅏ ㅐ ㅑ ㅒ ㅓ ㅔ ㅕ ㅖ ㅗ ㅘ ㅙ ㅛ ㅜ ㅝ ㅞ ㅟ ㅠ ㅡ ㅣ`）× 尾 8 種（無、`ㄱ ㄴ ㄹ ㅁ ㅂ ㅅ ㅇ`）共 2,128 個音節 ∪ 專案詞典全部用字（空白與 `-` 不列入檔，由字型固定含）。
  字型子集因此新增現行子集缺的 1,364 個音節（規則實跑全部 CMUdict 產生其中 978 個，其中 375 個不在現行子集；其餘是超集，保證規則調整後不必重建字型）；字型重建與 `font/characters.ko.txt` 同一個 commit。
- 專案詞典 lint：同規格 044 §3.5（`english` 集合為 85 個名字加補充名 `PIERRE`，ko 為 `피에르`），`translation` 每字在允許字集且 `charset.ko.txt` 含之；多字詞典項目以單一空白分隔（U+0020 與 `-` 豁免，首尾與連續空白不得有）。

### 3.4 接線與顯示

同規格 044 §3.6，`LangKo` 載入韓文音譯器。ECL 的 `譯名(英文)`、降段與名字註記不變。韓文名字與中文相近（85 個詞典名平均 ko 約 2.7 字、zh 約 2.6 字）。
**玩家名的續接呼叫起點空白**（規格 046 §3.4 明說 044、045 落地時回頭補）：ko 的玩家名在 ECL 續接呼叫時，適用規格 046 §3.4 的條件 1、2、4、5；條件 3（`koGlue`）不適用於玩家名單元，因為名字本身不是助詞（只譯名階層恰為助詞字串，如 `DOE` 得 `도`，會使空白被吃掉）。條件 2 的「本次輸出文字」包含玩家名單元與其英文退路。
實作位置：`ObserveEntry` 的 `if key == "player-name"` 區塊內，在 `spaceNeeded` 算出之後建立含空白變體：在原變體前加一個半形空白，`Units` 整體右移一格，空白不在單元內。
嘗試次序（與一般路徑相同，先降註記再降空白的相反：先含空白的全部階層、再不含空白的全部階層）：含空白的完整單元、含空白的只譯名單元、完整單元、只譯名單元、含空白的原文、原文；第一個排得下的採用。採用的候選不含空白、而含空白的候選已全部失敗時，`SpaceDropped` 加一。`PlayerNames`、`PlayerNameChineseOnly`、`PlayerNameEnglish` 的計法不變。
名字單元之後的續接呼叫，以單元最後一個字元（`)` 或諺文音節）為前一個畫出的字元，助詞照常黏接。`p == nil` 時玩家名的 `e.Original` 不會以空白開頭，不補空白；只有 `p != nil` 且前一次呼叫以空白結尾（`owedSpace`）時才補。
規格 046 §3.4（含條件 5 的次序文字）、§3.6 以本節為準，實作時加修訂註。

## 4. 不做什麼

同規格 044 §4 與 §3.8；另外不做詞尾助詞的收音選擇（`은(는)`、`이(가)` 仍用並列形，規格 046）。

## 5. 驗收

1. 單元測試：K1 至 K10 每條規則至少一個樣本（規則追蹤同規格 044 §5 第 1 點）；三層查找各有命中樣本；邊界輸入同規格 044；輸出不變式（對全部 CMUdict 純字母詞）：每個字元在允許字集內、沒有 Jamo、沒有 `·`。
   三字名（例 `ANNE MARIE SMITH`）的 `譯名(英文)` 單元：視窗寬大於單元時為單一 token；視窗寬小於單元時在每個空白切開，不丟字、不溢出、列首空白被捨去；單字名與雙字名同樣測試。玩家名續接空白的六個嘗試次序與 `SpaceDropped` 各一個測試；zh-TW（`layout` 為 nil）、ja（`layoutJa`）、zz 的玩家名續接，頁面（`Lines`、`endRow`、`endCol`）與 `Stats` 與改動前逐位相同（沿用規格 046 §3.5 的凍結副本做法，因為本節改的是三種語言共用的 `ObserveEntry` 區塊）；`DOE` 型只譯名恰為助詞字串時仍補空白。
2. 固定測試名單與期望輸出：同規格 044 §5 第 2 點的產生原則與入庫方式（`docs/re/phase-NNN-translit-fixed-names.ko.tsv`），規則覆蓋對象為 K1 至 K8（K9 由輸出不變式、K10 由 `ANNE MARIE SMITH`、`MARY-JANE` 涵蓋）；K8 的死分支（`NG` 補音）已刪除。
3. 專案詞典 `text/translit-ko-names.tsv`：85 個英文名，草擬後逐列審定，`basis` 記 `machine-reviewed`；lint 通過。
4. 字型：`translit-chars.ko.tsv` 與 `characters.ko.txt` 重建零缺字；載入期字型檢查通過；`ko_check.sh`、`lang_check.py` 通過；打包前置檢查與冒煙（規格 044 §3.7）通過。
5. 離線與同狀態：同規格 044 §5 第 5、6 點，對象為 ko（ja、zh-TW、zh-CN、en 逐位元相同）。
