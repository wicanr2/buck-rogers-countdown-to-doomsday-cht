# 045 — 韓文玩家名音譯（諺文）

狀態：**DRAFT**（2026-10-01）
日期：2026-10-01
Issue：#35
前置：規格 044（日韓共同前端 §3.1 至 §3.3、接線 §3.6，本規格只寫與 044 不同之處）、043（韓文）、037、038、036。

## 1. 為什麼要做

同規格 044 §1：韓文模式的玩家名以諺文音譯，格式「譯名(英文)」，窄欄只顯示譯名。規格 043 讓 ko 的 `PlayerNames` 停用（名字維持英文），本規格補上韓文音譯器。

## 2. 證據（已證實，除非標明）

- 接線點、CMUdict 覆蓋、原版名字限制：見規格 044 §2。
- 韓文字型字集（`font/charset.ko.txt`，11,273 字）含全部 11,172 個諺文音節；現行字型子集（`font/characters.ko.txt`）只含其中 1,057 個，音譯輸出要保證渲染，字型子集必須先含全部可能輸出的音節。
- 規格 043 §3.2：ko 禁用 `·`（U+00B7）與全形英數；名字表（`text/name-glossary.ko.tsv`）寫多字名用單一空白，例 `알렉산더 윌리엄스`；規格 043 §3.4 的詞級排版支援名字單位內含**單一**內部空白。
- 韓國《外來語標記法》的英語標記規則（國立國語院公告）是公開的標準；本規格的規則依其音韻對應整理，細節由專案詞典與固定名單校準，**母語者未校對**（規格 044 §6）。

## 3. 契約

### 3.1 介面、查找、前端

同規格 044 §3.1 至 §3.3：套件 `xlate/translitjk`，`Load(textDir, "ko")`，專案詞典 `text/translit-names.ko.tsv`，CMUdict，拼寫後備，同一組音素與元音字母對齊。

### 3.2 韓文：音素到諺文

**單位。** 音素串切成音節，每個音節是（頭子音、中聲、尾聲）三元組，最後以 Unicode 算式合成（`0xAC00 + (頭×21 + 中)×28 + 尾`）。

**3.2.1 頭輔音（接元音時）。** `P`→ㅍ，`B`→ㅂ，`T`→ㅌ，`D`→ㄷ，`K`→ㅋ，`G`→ㄱ，`F`→ㅍ，`V`→ㅂ，`TH`→ㅅ，`DH`→ㄷ，`S`→ㅅ，`Z`→ㅈ，`CH`→ㅊ，`JH`、`ZH`→ㅈ，`M`→ㅁ，`N`→ㄴ，`L`、`R`→ㄹ，`HH`→ㅎ；`NG` 不當頭。
`SH` 在元音前為ㅅ加舌面中聲：`샤`（`AA`）、`섀`（`AE`）、`셔`（`AH`、`ER`）、`셰`（`EH`）、`쇼`（`AO`、`OW`）、`슈`（`UW`、`UH`）、`시`（`IH`、`IY`）；`SH` 後的雙元音取其第一元音套用此列。

**3.2.2 中聲。**

| 音素 | 中聲 | 備註 |
|---|---|---|
| `IY`、`IH` | ㅣ | |
| `EY` | ㅔ＋`이` | 雙元音拆成兩個音節：`Kate` 케이트 |
| `EH` | ㅔ | |
| `AE` | ㅐ | |
| `AA` | ㅏ；拼作 `o` 時為ㅗ | `Scott` 스콧 |
| `AH` | 有重音：ㅓ；無重音：對應字母 `a`→ㅏ，其餘（含無字母）→ㅓ | |
| `AO`、`OW` | ㅗ | |
| `UW`、`UH` | ㅜ | |
| `AW`、`AY`、`OY` | ㅏ＋`우`、ㅏ＋`이`、ㅗ＋`이` | 同 `EY`，拆兩個音節 |
| `ER` | ㅓ（r 不另譯） | `Peter` 피터 |

半元音：`Y`＋元音得 `야`（`AA`、`AE`）、`여`（`AH`、`ER`）、`예`（`EH`）、`유`（`UW`、`UH`）、`요`（`AO`、`OW`）、`이`（`IY`、`IH`）；`Y`＋雙元音取第一元音。
`W`＋元音得 `와`（`AA`）、`왜`（`AE`）、`워`（`AH`、`AO`、`ER`）、`웨`（`EH`）、`위`（`IH`、`IY`）、`우`（`UW`、`UH`、`OW`）；`W`＋`EY` 為 `웨`＋`이`，`W`＋`AY` 為 `와`＋`이`。

**3.2.3 元音後的 r 與無元音的輔音。**

- `R` 在元音前是頭 `ㄹ`；在元音後、輔音或詞尾前不譯（`Park` 파크、`Carl` 칼），`ER` 見上表。
- 不接元音的輔音：`M`、`N`、`NG` 為前一音節的尾 `ㅁ`、`ㄴ`、`ㅇ`；`L` 為尾 `ㄹ`（`Bill` 빌）。前一音節已有尾，或詞首沒有前一音節時，補 `으`（`ㅡ`）成獨立音節。
- 無聲塞音 `P`、`T`、`K`：緊接在**短元音**（`IH EH AE AH AA UH`）之後，且在詞尾，或後面接 `L R M N` 以外的輔音時，為尾 `ㅂ`、`ㅅ`、`ㄱ`（`Jack` 잭、`Scott` 스콧、`Jackson` 잭슨）；其餘情形補 `으`（`프`、`트`、`크`）。
- 其餘輔音（`B D G F V TH DH S Z CH JH ZH`）不接元音時補 `으`：`브 드 그 프 브 스 드 스 즈 치 지 지`；`SH` 在詞尾為 `시`、在輔音前為 `슈`；`HH` 補 `흐`。
- 尾只用 `ㄱ ㄴ ㄹ ㅁ ㅂ ㅅ ㅇ`。沒有促音、沒有長音符號。

**3.2.4 組成。** 多字名以單一空白（U+0020）連接；連字號的各段以 `-`（U+002D）連接。`tier` 取各字最低。名字單位內有多個空白時詞級排版的行為見 §6。

### 3.3 允許字集與字型

- 允許字集 = 頭子音 14 個（`ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ`）× 中聲 19 個（`ㅏ ㅐ ㅑ ㅒ ㅓ ㅔ ㅕ ㅖ ㅗ ㅘ ㅙ ㅛ ㅜ ㅝ ㅞ ㅟ ㅠ ㅡ ㅣ`）× 尾 8 種（無、`ㄱ ㄴ ㄹ ㅁ ㅂ ㅅ ㅇ`）共 2,128 個音節 ∪ {空白、`-`} ∪ 專案詞典全部用字。
  專案詞典 lint：每個 `translation` 的字都要在允許字集內，且字型字集（`charset.ko.txt`）含之。
- 工具 `tools/translit_jk.py chars --lang ko` 產生 `text/translit-chars.ko.tsv`，字型子集因此固定包含這些字；字型重建與 manifest 雜湊重記依規格 043 的註記。

### 3.4 接線與顯示

同規格 044 §3.6，`LangKo` 載入韓文音譯器。ECL 的 `譯名(英文)`、降段與名字註記不變。韓文名字短於日文，通常與中文相近。

## 4. 不做什麼

同規格 044 §4；另外不做詞尾助詞的收音選擇（`은(는)`、`이(가)` 仍用並列形，規格 046）。

## 5. 驗收

1. 單元測試：§3.2 每個表格列與每條規則至少一個樣本；三層查找各有命中樣本；含數字或標點的名字與單一字母名回 `ok=false`；`O'BRIEN`、`MARY-JANE` 正常；輸出每個字元在允許字集內；決定性；輸出沒有 `ㅇ` 以外的單獨子音字母（Jamo）、沒有 `·`。
2. 固定測試名單與期望輸出：同規格 044 §5 第 2 點的名單（約 60 個），期望值入庫前過兩位獨立審查者。
3. 專案詞典 `text/translit-names.ko.tsv`：85 個英文名，草擬後逐列審定，`basis` 記 `machine-reviewed`；lint 通過。
4. 字型：`translit-chars.ko.tsv` 與 `characters.ko.txt` 重建零缺字；`ko_check.sh`、`lang_check.py` 通過。
5. 離線與同狀態：同規格 044 §5 第 5 點，對象為 ko。

## 6. 開放項目

| 項目 | 消除條件 |
|---|---|
| 規則依標記法整理、母語者未校對；有重音的 `AH` 取 ㅓ 與無重音依字母取 ㅏ 的假設 | 母語者校對固定名單與詞典 |
| 名字單位內有兩個以上空白（三個字以上的名字）時，規格 043 §3.4 的詞級排版只涵蓋單一內部空白 | 實作時以單元測試確認；不支援時第三個字以後與前一字無空白相連，並回寫本節 |
| `B D G` 詞尾補 `으`（`Bob` 보브）與慣用寫法（`밥`）不同 | 專案詞典覆蓋常見名 |
