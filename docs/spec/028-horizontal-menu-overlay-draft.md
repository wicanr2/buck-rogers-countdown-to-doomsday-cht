# 028 — 水平選單與提示列通用覆繪（逐項字典）

狀態：**READY**（2026-09-26 獨立審查後補三處規則）；§3.4 遮罩格讓位修訂 2026-09-27 審查後 READY、同日驗收 **CONFORMED**（phase-275 §3）
日期：2026-09-26
前置：[第二百五十七階段](../re/phase-257-horizontal-menu-printer.md)、規格 027、
規格 023（第 24 列既有停止線；本規格取代其「不授權新增 TSV」的限制範圍，只限本程序）。

## 1. 為什麼要做

遊戲本體第 24 列的指令列（`Move Area View Look Change Save`）、移動模式的 `Exit`、
事件後的 `Press button or enter to continue`，以及 ECL 劇本的是非／選項選單，
都由 `37F1:0243` 這支程序畫出。原版把選單拆成項目，每個項目是一段英文，
其中大寫字母與數字以熱鍵色顯示，目前選取的項目以反白顯示。

選單是執行期組合的（`GAME.OVR` 裡是逐項 Pascal 字串），整串雜湊無法事先列舉；
改以「項目」為翻譯單位。

## 3. 契約

### 3.1 catalog

- `text/hmenu-item-events.tsv`：`event_key`、`original_length`、`original_sha256`。
  一個項目的原文是項目表範圍內的子字串，去除頭尾空白。
- `text/hmenu.zh-TW.tsv`：`key`、`translation`、`source`。
- 譯文中的 ASCII 大寫字母與數字以熱鍵色畫出；譯者只在熱鍵處使用大寫 ASCII，
  格式建議 `中文(X)`，X 是原版該項的熱鍵字母，玩家照原版按鍵操作。

### 3.2 識別與呈現

- 在 `CS:IP = 37F1:0243` 讀取父框架資料。項目數為 0、項目範圍
  超出字串、或任一項目不在 catalog（或缺譯文）時，不畫，並清除該列既有呈現。
- 全部命中時，依原版項目順序排列譯文，項目間一格空白，每列從該列第一個項目的原版欄位開始
  （選單字串開頭可能有空白；修訂，見 phase-259）；
  選取項整段以反白色畫出（優先於熱鍵色，與原版 `37F1:02C9` 先判範圍相同）；
  其餘項目中，ASCII 大寫字母與數字以熱鍵色、其他以一般色畫出。總寬超過 `40 − 起始欄` 時不畫。
- `@`（修訂，2026-09-26 戰鬥選單樣本）：原版遇 `@` 清除本列剩餘、列加一、回起始欄
  （`37F1:0292`–`02C6`）。項目所在列 = 起始列 + 其起始字元前的 `@` 個數；
  每列各自從起始欄排，各列寬度各自檢查。
- 遮罩：每個用到的列，從起始欄到第 39 欄。

### 3.3 呼叫期間與失效

- 呼叫期間：進入到驗證過的返回（返回位址、`SS`、`SP = 進入 SP + 4 + 4`）。
  期間內與遮罩相交的寫入是原版繪製，不失效。
- 呼叫期間外，A000 寫入與遮罩相交 → 清除。
- 呼叫期間外再次進入 `37F1:0243`（選取項變動或換選單）→ 以新資料重建。
- 呼叫期間內再次進入（巢狀或重入）→ 整列呈現失效，退回英文。
- 其他程序（如 dispatcher `0763:1307` 的 `Loading...`）寫第 24 列時，依「呼叫期間外
  寫入相交」規則清除，兩個家族互相讓位、失敗時退回英文。
- 執行不連續 → 清除。

### 3.4 與既有家族並存（修訂，見 phase-259）

合成時若合成順序在本家族之前的其他家族，已改動本家族**遮罩格**內任一輸出像素，本家族整頁不畫。
既有家族有各自審查過的 catalog 與幾何，優先於通用字典。
- 遮罩格：每個有項目的列，從該列第一個項目的原版欄位（0 起算，與 §3.2 排版起點、§3.3 失效範圍
  同一組格）到第 39 欄；`@` 分出的各列各用自己的起點；沒有項目的列不在遮罩內。
- 判讀方式：已合成畫面與原版放大逐輸出像素比較（2×／3× 每個像素，不取樣）。
- 遮罩外的改動（例如同列左側由舊選單家族覆繪的提示）不影響本家族。
- 合成順序在本家族之後的家族（規格 029 引擎行、規格 030 手札）不使本家族讓位；它們依各自規則
  對本家族讓位。
- 修訂緣由見 phase-275（2026-09-27，Issue #27）。
- 驗收：合成測試（改動在 `起點欄−1` 照畫、在起點欄整頁不畫；前導空白使起點欄右移時，其間的改動
  照畫；`@` 兩列各自判讀；3× 只改一個非取樣位置像素也判為改動）；功能選單同狀態 A/B（2×／3×）
  第 24 列 `Select` 顯示中文，遮罩外舊家族像素與修訂前逐像素相同，同列 `Choose a FUNCTION `
  行為不變，連續多影格判定穩定；phase254 七條回歸。

### 3.5 ECL 選單項目的大小寫（修訂 2026-09-26，Salvation III 樣本）

ECL 檔中的選單項目是全大寫（例如 `ORDER FOOD`），引擎印出時只有首字大寫
（`Order food`、`Hq`）。逐項查表未命中時，把項目轉成全大寫再查一次；原字串本來就是
全大寫時不重查。印字程序的位址依規格 032 以 overlay unit 表示。

## 4. 不做什麼

- 不處理 dispatcher `0763:0424` 的字串（隊伍表、座標列、`Loading...`）。
- 不改熱鍵、按鍵處理或選取行為。
- 不處理項目跨越 `@` 的情形（項目範圍內含 `@`）；遇到時退回英文。

## 5. 驗收

1. 單元測試：全命中、單項未命中、`@` 兩列、項目含 `@`、超寬、選取變動、呼叫外寫入、返回驗證、呼叫內重入。
   起始欄非零尚無執行期樣本，只以單元測試覆蓋。
2. 原版同狀態：主指令列（選取 1、2）、`Exit`、`Press button...` 各一個時間點，
   2×／3× 差異只在第 24 列遮罩內。
3. 正常玩家路徑：選取移動、進出移動模式、事件提示後按鍵清除，不殘字。
