# 034 — 手冊查詢題的英文關鍵字列

狀態：**DRAFT**（2026-09-27）
日期：2026-09-27
前置：規格 002、005、024（手冊段落覆繪與 presenter）、phase-12（題庫結構）、phase-270。

## 1. 為什麼要做

原版手冊查詢題要玩家輸入英文手冊某段的第 N 個字（N = 1–10）。目前畫面保留英文題幹、在下方覆繪
中文手冊段落；中文段落沒有英文單字，沒有英文手冊或中文版 Data Card 的玩家無法作答。
使用者決定（2026-09-27）：在中文段落下方另列該段英文原文的前 N 個字，標出第 N 個字。
答案仍由玩家輸入、原版比對，不改判定、不自動填入。

## 2. 證據

- 英文原文來源：使用者本機的英文手冊快照 `workplace/buckrogers-original-manual-english.html`
  （phase-112 記錄其 SHA-256）。它是 OCR 文字，有錯字；至少一題的第 N 個字受 OCR 錯誤影響（已證實）。
- 答案與摘錄單字不得出現在規格、`docs/re`、commit、Issue、收據 JSON、除錯輸出與測試 fixture。
- 題目 metadata（頁碼、標題、序數）已由 phase-12 證實；答案欄編碼與比較流程已證實，原規定
  「禁止匯出」。
- 手冊段落版面（`manual-overlay-layout.tsv`）：文字區 x 16、y 72，36 欄 × 14 列，每列 8 邏輯像素。

## 3. 契約

### 3.1 資料（只在本機）

- `workplace/manual-english/excerpt.tsv`（ignored，不進 Git、公開包或 Issue）：
  `event_key`（對應 `text/manual-events.tsv`）、`ordinal`、`words`（該段英文前 N 個字，以單一空白分隔）。
- 由 `tools/manual_english_excerpt.py` 從英文快照依標題定位產生；OCR 錯字以同目錄的人工更正檔
  （ignored，`event_key`、`index`、`word`）覆寫，更正檔每列要附理由。
- 靜態核對（本機）：同一工具以原版資料段解碼題庫答案欄，只比對「第 N 個字（去標點、不分大小寫）
  等於答案」，輸出通過數與失敗的 `event_key`，**不輸出、不保存答案內容**。39 筆全部通過才產生
  `excerpt.tsv`；有失敗就不產生。這是答案欄在本專案唯一的用途，執行期不讀答案。

### 3.2 執行期

- `LiveRuntime` 新增選用輸入：英文摘錄檔路徑（`buckrogers-play` 與 receipt runner 以旗標傳入）。
  沒給或檔案不存在時功能關閉，其他行為不變。載入時核對 `event_key` 都在手冊事件表、`ordinal`
  與事件表相同、`words` 恰為 N 個字且只含可列印 ASCII；任一不符就整個功能關閉並記一次重設。
- 顯示時機：手冊段落呈現（規格 005）為作用中、且其請求的 `event_key` 在摘錄檔中。手冊段落
  關閉或換題時同時關閉，不另有壽命規則。
- 排版：
  1. 取與手冊段落相同的斷行結果得到中文段落列數 k；英文從第 k + 2 列開始（空一列）。
  2. 長式：前綴「英文原文（第 N 字）：」接前 N 個字，第 N 個字以「〔」「〕」括起；以字為單位
     換行，一個字不拆開，每列 36 欄。
  3. 長式放不下 14 列時改用短式：「英文第 N 字：」＋第 N 個字，一列。
  4. 短式也放不下就不顯示，記一次 overflow。
  - 英文字母、數字每字元佔 1 欄，用原版 8×8 字形（規格 031 的 `.orig-ascii` 字型）；中文前綴與
    括號用手冊字型。
- 繪製：不透明，底色與前景色與手冊段落相同；只畫在手冊清除矩形內，不超出。
- 不改原版記憶體、不送鍵、不改答案比對；手冊段落本身的呈現與身分檢查不變。

### 3.3 不做什麼

- 不翻譯英文題幹（規格 002 的使用者決定保留原版題目）。
- 不在摘錄檔以外的來源取英文，不從遊戲記憶體讀答案顯示。

## 4. 驗收

1. 單元測試：載入核對（缺欄、`event_key` 不存在、序數不符、字數不符、非 ASCII）；長式、短式、
   不顯示三種排版；第 N 個字括號；手冊關閉與換題時一起關閉；功能關閉時畫面與現行逐位元相同。
2. 靜態（本機）：39 筆摘錄全部通過答案核對；摘錄與更正檔不在 Git 追蹤範圍。
3. 原版同狀態：讀檔後的手冊問答（phase-270 `gq1` 路徑）與至少一筆不同序數的題目，2×／3×
   差異只在手冊清除矩形內；功能關閉時與現行收據逐位元相同；以畫面顯示的字作答，原版接受並回到
   站內（遊戲記憶體與正常作答收據相同）。
