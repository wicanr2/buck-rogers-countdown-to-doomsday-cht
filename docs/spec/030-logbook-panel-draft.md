# 030 — 手札（Log Entry）遊戲內面板

狀態：**READY**（2026-09-26 兩輪獨立審查後）；§3.3 關閉條件 4 為 **DRAFT** 修訂（2026-09-27），審查通過前不實作
日期：2026-09-26
前置：規格 027（敘事窗）、規格 029（引擎訊息）、Issue #23、
[第二百六十一階段](../re/phase-261-logbook-message.md)。

## 1. 為什麼要做

原版在事件後印出「……記為第 N 則手札」，要玩家翻手冊讀第 N 則。使用者 2026-09-26 指示：
手札內容直接在遊戲內顯示，不必查手冊。這是原版實際要求手冊的情境，符合 AGENTS.md
「中文段落只在原版要求手冊時顯示」的邊界。

## 2. 原版證據（摘要）

- `GAME.OVR` 檔案位移 11,669 起的三個常數（長度 16、18、1）與字串變數 `DS:6EDC`、手札編號
  （ECL 運算元轉成的數字）串成一整串，以清窗旗標 0、`DS:5F40`–`5F43` 視窗呼叫
  `0763:056C`（位元組，已證實；見 phase-261）。整串以「數字＋句點」結尾，
  接在前一段敘事之後。
- 手冊共 71 則手札；中文印刷本編號與英文版一致（第 53–56 則逐一比對，已證實）。
- 執行期（phase-263，已證實）：第 41 則在 Salvation III 觸發，整串以「entry 41.」結尾，
  數字無補白；返回後 `00B8:007F` 沒有寫入敘事窗。其他 29 個觸發點未量。

## 3. 契約

### 3.1 資料

- `text/logbook.zh-TW.tsv`：`key`（`logbook.N`，N 為 1–71）、`translation`、`source`。
  內容是對照中文印刷本的遊戲內意譯，不是逐字轉錄；段落以 `\n` 分隔；每則 ≤ 1,000 字。
- 標題另存 `logbook.N.title`。

### 3.2 識別

- 在 `0763:056C` 進入時（規格 027 的讀取點），若整串以 ` as logbook entry ` 加任意個空白、
  1–2 位數字、`.` 結尾（`0653:13AC` 的輸出格式未量，容忍前導空白）（比對以片段雜湊確認 ` as logbook entry ` 為規格 029 catalog 內的片段），
  取出 N。N 不在 1–71 或缺譯文時不開面板。
- 整串本身的敘事窗顯示照規格 027／029 處理（前半若是 ECL 字串則另行查表）。

### 3.3 呈現

- 面板畫在 `[8,312)×[16,184)`（邏輯像素），36 欄 × 21 列格線：第 1 列是「手札第 N 則：標題」，
  第 21 列留給頁碼，正文可用 19 列 × 36 格 = 每頁 684 格。正文依段落換行（段落另起一列），
  拉丁字母與數字連續不拆行，全形句讀不放行首。
- 每則最多 3 頁；排版後超過 3 頁的譯文在靜態驗證就失敗，不進正式檔。
- 超過一頁時，第 21 列右側顯示「第 1／2 頁」。翻頁由前端 host 按鍵處理（PgDn／PgUp），
  不送進遊戲；沒有前端時只顯示第 1 頁，頁碼列照常顯示總頁數。
- **關閉條件獨立於規格 027 的敘事窗失效**（原版在 `056C` 返回後還呼叫 `00B8:007F`，
  其寫入行為未量，不能讓它提早關閉面板）：
  1. 下一次 `0763:056C` 進入（原版開始印下一段文字）；
  2. 敘事窗整塊被清除：一次清除寫入同時涵蓋敘事窗左上與右下格；
  3. 執行不連續（restore、observer fault）。
  4. （DRAFT 修訂 2026-09-27）面板開啟後，遊戲經 `int 16h` 實際取走一個鍵
     （dosgolem `KeysConsumed` 比開啟當下多 1 以上）。在下一次畫面合成時關閉。
  其他 A000 寫入不影響面板。

  條件 4 的依據：第 17 則（ECL2 區塊 33，phase-272 §6）原版印完手札訊息後回到冒險選單，
  敘事窗文字一直留著；玩家轉向、移動時 3D 視窗與座標列都更新，但不會再進 `056C`，
  也不整窗清除。只靠條件 1–3，面板會一直蓋住畫面，玩家看不到自己的移動。
  同狀態量測：`056C` 返回後只有 `0C10:0303` 的 `int 16h` AH=01 查鍵，直到玩家按下 Enter
  才有取鍵（`0C10:0303`／`031A`，主程式段）；中間沒有取鍵。
  - 用通用計數而不是遊戲位址：取鍵點在主程式段，但判準「玩家按了鍵、遊戲收下了」與位址無關。
  - 前端的翻頁鍵（PgDn／PgUp）由 host 處理、不送進遊戲，不計入。
  - 已知限度：玩家在面板開啟前已預先按下、仍在 BIOS 緩衝區的鍵，遊戲一取走面板就關，
    面板可能只出現一瞬間。原版同樣會立刻吃掉那個鍵，視為與原版一致，不另外攔。
  - 關閉後露出的是原版敘事窗（已由規格 027／029 覆繪成中文），不是空白。
- 面板不改遊戲狀態：不寫 DOS 記憶體、不送鍵、不改計時。

### 3.4 與既有手冊段落

`text/manual.zh-TW.tsv` 的 15 筆 `manual.log.*` 是手冊題目家族用的段落，維持原樣；
本面板一律用 `text/logbook.zh-TW.tsv`。兩者由不同批次產生，用詞以術語表對齊，
不互相引用。

## 4. 不做什麼

- 不改原版流程、不自動按鍵、不在原版沒提到手札時顯示。
- 不提供手札瀏覽選單（另案）。

## 5. 驗收

1. 單元測試：句尾辨識（1–2 位數、前導空白、缺譯文、N 超界）、分頁排版、四種關閉條件、
   非整窗寫入不關閉；取鍵計數不變時不關閉。
2. 靜態：71 則譯文驗證（Big5、無頭尾空白），並以與執行期相同的排版確認每則 ≤ 3 頁；
   字型覆蓋。
3. 原版同狀態：至少一次手札觸發，開面板前後遊戲狀態雜湊相同；量測 `00B8:007F` 的寫入與
   `0653:13AC` 的數字格式，回填 phase-261；面板在下一段文字或整窗清除時關閉。
   **第 41 則（phase-263）、第 21、38、50 則（phase-272）已通過**：面板開啟、下一段文字時關閉，2×／3× 遊戲記憶體雜湊相同。
   存讀檔後不殘留尚未量測。
4. 面板以不透明矩形繪製（修訂 2026-09-26：差異疊層會讓前一層中文透出），
   顏色取觸發呼叫的前景／背景索引；標題與頁碼模板在 `text/logbook-panel.zh-TW.tsv`。
